## FR (reference language)

**Mini-applications Pentaflowers (CyberPlan, ElectroPlan).** Lorsque vous utilisez nos mini-applications, la description du produit ou du projet que vous saisissez est envoyée à notre fournisseur d'intelligence artificielle (Anthropic) uniquement pour proposer des réponses ou rédiger le texte du rapport. Nous ne la conservons pas. Selon les conditions commerciales du fournisseur, les données envoyées par API ne servent pas à entraîner ses modèles. Le fournisseur est établi aux États-Unis : les garanties décrites dans la section sur les transferts hors de l'Union européenne s'appliquent. Les résultats réglementaires sont calculés par notre code, jamais par l'intelligence artificielle. Les coordonnées que vous laissez pour recevoir le rapport (nom, prénom, e-mail, entreprise, fonction, pays, consentements) et les principaux résultats de l'analyse sont conservés jusqu'à 3 ans après le dernier contact si vous avez accepté d'être recontacté, et sinon uniquement le temps nécessaire pour vous envoyer le rapport et prouver votre consentement. Les documents téléchargés, lorsque cette fonction sera disponible, sont supprimés après 1 mois.
